Cara nonton:
- **Dari web (Pages)**: di panel Bioskop klik **📂 Putar dari folder komputer**, pilih folder `D:\teather` di PC. File diputar langsung dari PC (gak di-upload).
- **Lokal (server lokal di folder repo)**: taruh video di sini, jalankan `python3 tools/theater-list.py` → `videos.json` ke-update, semua film muncul di daftar "Folder theater/".
